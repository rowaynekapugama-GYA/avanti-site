# Discount codes: how to use them

Discount codes take money off the **shipping** or off the **products**. Customers type the code at
checkout, just under Delivery. Only one code works per order.

## Make a new code

1. Sign in to the dashboard and click **Discounts** (under Orders).
2. Click **New code**.
3. **Code**: what the customer types, for example `FREESHIP` or `SAVE10`. Letters and numbers
   only, no spaces. Customers can type it in capitals or lower case.
4. **Description**: a note for staff, for example "Newsletter offer, November". Customers never see it.
5. **What does the code take money off?** Shipping or Products.
   - For Products, choose **All products** or **Only the products I choose**, then tick the
     products. Use the search box to find them.
6. **How much off?** A percentage (for example 10) or a dollar amount (for example 20).
   - Free shipping: Shipping, percentage, 100.
   - A dollar amount on chosen products comes off once per order, not once per item.
7. Rules, all optional:
   - **Minimum order**: the products total the order must reach before the code works.
   - **Start date / End date**: the code works from the start of the start date to the end of
     the end date, Sydney time.
   - **Total uses**: how many paid orders can use it altogether.
   - **Uses per customer**: how many times one email address can use it.
8. Leave **Switched on** ticked and click **Create code**.

## What customers see

- The discount appears in the order summary, for example "Shipping discount (FREESHIP) -$15.00",
  and the total and GST update straight away.
- If a code can't be used they see one of these: "That code isn't valid", "That code has expired",
  "That code has already been used the maximum number of times", or "Your order needs to be at
  least $X to use this code".
- If they enter a second code, it replaces the first and they're told so.

## Good to know

- Prices include GST. The discount comes off the GST-inclusive price, and the GST shown on the
  order and emails is worked out on the discounted amount.
- A code never takes off more than the shipping or products it applies to.
- A use only counts once the order is **paid**. Unfinished checkouts don't use it up.
- Refunding or cancelling an order doesn't give the use back.
- Limits are counted when payment goes through. If two people are paying with the same limited code
  at the same moment, it can go one over its limit. For a code worth a lot, keep the limit tight.
- Pick codes that are hard to guess for bigger discounts (for example `VIP7KQ2` rather than `VIP`).

## The Discounts list

Each code shows what it applies to, the discount, uses (used / limit) and a status:

| Status | Meaning |
| --- | --- |
| Active | Customers can use it now |
| Scheduled | The start date hasn't arrived yet |
| Expired | The end date has passed |
| Used up | It has reached its total uses |
| Inactive | It has been switched off |

Click a code to change it, switch it off, or see the orders that used it.

## Switching a code off or deleting it

- **Switch off (deactivate)** stops it working straight away. You can switch it on again later.
- **Delete code** only appears while the code has never been used on a paid order. Once it has
  been used, switch it off instead, so the order history stays complete.
- A used code can't be renamed. Switch it off and make a new one.

## Each order

Open any order in **Orders**. The discount shows in the items table (Product discount or
Shipping discount) and under Payment, with the code and how much the customer saved.
