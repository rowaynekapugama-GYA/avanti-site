# Eyelets: how to set the choices and prices

The **Eyelets** dropdown shows on Corflute Signs (standard sizes) and Corflute Signs - Custom Dimensions.
Both products always show the same list, so you only set it up once.

## Where to find it

1. Log in to the dashboard at avantiprint.com.au/#/admin.
2. In the menu, under **Commerce**, click **Eyelets**.

## Add a choice

1. Click **Add choice**.
2. **Label customers see**: the words in the dropdown, for example "One in each corner" or "Every 500mm around the edge".
3. **Price**: choose one of:
   - **No extra charge**
   - **Amount per sign**: the amount is added to the price of each sign
   - **Amount per eyelet**: the amount is charged for every eyelet on each sign
4. **Amount**: in dollars, including GST.
5. For **Amount per eyelet**, choose **Number of eyelets**:
   - **Set number**: the same number on every sign, for example 4 for the corners
   - **Around the edge**: one in each corner, then no more than the spacing you enter apart, all the way around
   - **Along the top**: along the top edge only, both top corners included

   For the last two, enter the spacing in mm. The website works out the number from the sign's size, and the
   example under the choice shows what a 600 × 400 and a 1200 × 2400 sign would get.
6. Click **Save choices**.

Changes show on the website as soon as you save. Customers see the number of eyelets and the extra cost
before they add the sign to their cart.

## Change a price or a label

Change it on the same page and click **Save choices**. Orders already placed keep the price and wording
they were charged.

## Change the order

Use the arrows (or drag the dots) to move a choice up or down, then **Save choices**.

## Stop offering a choice

Untick **Shown to customers** and click **Save choices**. It disappears from the dropdown but stays on the
page, so you can turn it back on later. Old orders still show what the customer chose.

**Remove** deletes a choice from the list altogether. Old orders still show it.

## The default

The choice with **Default choice** ticked is selected when the product page opens. Keep it as
**No eyelets** so nobody pays for eyelets by accident. There must always be exactly one default, and it
must be shown to customers.

## Good to know

- Prices include GST, the same as the rest of the website. GST on the invoice includes the eyelets.
- A discount code comes off the eyelets as well, the same as the rest of the sign's price.
- The tax invoice and the order emails show the choice, the number of eyelets and the extra cost on the
  sign's line, for example "Every 500mm around the edge (6 eyelets, +$3.00 per sign)".
- To show the dropdown on another product, open the product in **Products** and tick
  **Show the Eyelets dropdown on this product**.

If anything looks wrong, don't change it. Send GYA the order number or a screenshot.
